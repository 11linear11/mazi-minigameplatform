

نمونه اولیه رابط کاربری برای پلتفرم چت + مینی‌گیم.

## اجرای پروژه

ابتدا وابستگی‌ها را نصب کنید:

```zsh
npm install
```

اجرای محیط توسعه:

```zsh
npm run dev
```

## اجرای Backend (فاز 3)

```zsh
cd server
npm install
npm run dev
```

## ساختار
- `src/app/page.tsx` صفحه اصلی سه‌ستونه
- `src/components/*` کامپوننت‌های UI
- `src/data/mock.ts` داده‌های نمونه
 - `server/index.js` سرور Socket.IO نمونه

## یادداشت
این نسخه فقط UI و داده‌های Mock دارد و به Backend متصل نیست.
