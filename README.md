# پلتفرم چت و بازی آنلاین (GameChat Platform)

پلتفرم مدرن و بلادرنگ برای چت گروهی، ساخت اتاق‌های گفتگو و اجرای همزمان مینی‌گیم‌های چندنفره (شطرنج، اوونو، دوز، نقطه‌بازی و قفل‌گشا).

---

## 🚀 راهنمای اجرای سریع پروژه

### روش اول: اجرای مستقیم محلی (پیشنهادی)

#### ۱. راه‌اندازی سرور بک‌اند (Backend Server):
```bash
cd server
npm install
npm run dev
```
سرور روی آدرس `http://localhost:4000` آماده به کار خواهد شد.

#### ۲. اجرای فرانت‌اند (Frontend Dev Server):
در پنجره یا تب جدید در ریشه پروژه:
```bash
npm install
npm run dev
```
اپلیکیشن روی آدرس `http://localhost:3000` در دسترس خواهد بود. درخواست‌های سوکت و API به طور خودکار به سرور بک‌اند پروکسی می‌شوند.

---

### روش دوم: اجرا با داکر (Docker Compose)

```bash
docker compose up -d --build
```
کانتینرهای بک‌اند (`port 4000`) و فرانت‌اند (`port 3000`) راه‌اندازی خواهند شد.

---

## 🧪 اجرای تست‌های خودکار

تست‌های واحد بک‌اند با تستر نیتیو Node.js پیاده‌سازی شده‌اند:

## 🎮 بازی‌های پیاده‌سازی‌شده
- **شطرنج (Chess):** بازی دو نفره استاندارد با اعتبارسنجی قوانین شطرنج و اینترفیس Lichess Chessground
- **اوونو (Uno):** بازی کارتی کلاسیک ۲ تا ۴ نفره همراه با افکت کارت‌های ویژه
- **دوز (Tic Tac Toe):** بازی دو نفره سنتی و سریع
- **قفل‌گشا (LockPick):** چالش سرعتی دو نفره تطابق رنگ‌ها و حلقه‌ها با تایمر
- **نقطه‌بازی (Dots & Boxes):** بازی دونفره خط و تصاحب جعبه‌ها
